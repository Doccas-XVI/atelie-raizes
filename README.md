# Ateliê Raízes

O Ateliê Raízes é um projeto acadêmico desenvolvido para um cliente real, com o objetivo de criar uma solução digital para um ateliê de cerâmica artesanal.

A proposta surgiu da necessidade de organizar o processo de vendas, reduzir a dependência do atendimento via WhatsApp e proporcionar uma experiência de compra mais estruturada, valorizando a identidade e o processo de produção artesanal.

A plataforma permite a apresentação de produtos, solicitação de peças personalizadas e gerenciamento de encomendas. Também contempla funcionalidades administrativas para organização de produtos, estoque, pedidos e clientes.

Mais do que desenvolver uma aplicação, o projeto envolveu compreender as necessidades do cliente, estruturar requisitos e transformar problemas reais em uma solução tecnológica.

## Objetivos

- Aplicar conhecimentos de desenvolvimento web em um cenário real.
- Compreender e levantar requisitos junto ao cliente.
- Digitalizar e organizar o processo de vendas.
- Facilitar o gerenciamento de encomendas e produtos.
- Desenvolver uma solução alinhada às necessidades de um negócio artesanal.
